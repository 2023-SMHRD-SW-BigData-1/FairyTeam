# 당신편 원본 기획 요약 (2023 SMHRD 요정팀)

> 원본 산출물(`doc/01.핵심기획발표`, `doc/02.요구사항정의`의 기획서·요구사항정의서·화면설계서·
> 테이블명세서·시연자료 PPT/PDF)의 **핵심 내용을 추려 보존**한 문서.
> 무거운 원본 바이너리(PPT 24MB 등)는 이 요약 작성 후 정리(삭제)함. 정리: 2026-06-14.

## 1. 프로젝트 개요
- **과제명**: 위치기반 API 서비스를 이용한 **편의점 직/위탁거래** (중고거래 플랫폼)
- **서비스명**: 당신편 (= "당신 곁의 편의점" / "당신 편")
- **팀**: 요정팀 — 박충희(팀장, BE/FE), 김호현(BE/Chat), 박예은(BE/FE/Design), 조수민(FE/Design), 김태경(BE)
- **기간**: 2023.06.08 ~ 07.19 (기획→요구분석→설계→구현→테스트→통합)

## 2. 기획 배경 (왜 만들었나)
- 직거래 = 낯선 사람과 만나는 위험 / 택배거래 = 느리고 사기 위험
- → **24시간 + CCTV + 점원(증인)이 있는 편의점**에서 직·위탁거래하면 안전
- 위탁거래: 판매자가 편의점에 맡김 → 구매자가 시간 압박 없이 픽업 (비대면)
- 기대효과: 안전범죄 예방, 편의점 마케팅 효과, 거래시간 제약 없음, 중고 재사용(환경)
- 데이터: 당근/번개장터/중고나라 **크롤링**으로 초기 상품 확보(원본), 카카오지도·결제 API

## 4. 화면 설계 (화면설계서 11화면)
1. **Main** — 로고 / 검색창("상품명, 지역명, @상점명") / 로그인·회원가입 / Header / MainSection(배너+오늘의 상품 추천 + 우측 찜한상품·최근본상품·TOP)
2. **Category** — 대분류/중분류/소분류 3단 메뉴
3. **Product(상세)** — 물품사진·제목·가격·찜·채팅하기·물품내용 (안전결제 수수료무료, ⚡페이, 연관상품)
4. **JJim(찜)** — 탭(상품/상점후기/찜/팔로잉/팔로워) + 정렬 + 선택삭제
5. **Product Registration** — ①사진(최대12장 640x640)·제목·카테고리(대중소) ②거래지역(내위치/주소검색)·상태(중고/새)·교환·가격(배송비포함)·설명·연관태그·수량
6. **Join** — 아이디·비밀번호·이메일·이름·생년월일
7. **Login** — ID/일회용번호/QR 탭, 로그인상태유지·IP보안

## 5. 브랜드 / 디자인 (시연자료)
- **로고/브랜드 색 = 청록(teal/민트)**, 줄무늬 차양 편의점 아이콘 + "당신편"
- 슬로건: "직,위탁거래 서비스 플랫폼 / 당신 곁의 편의점"
- 기술스택(원본): React+JS / Node+Python / MySQL / GitHub / VSCode

## 6. 원본 DB (테이블명세서) — 6테이블
- user_info(회원), product_info(물품), prod_category_info(카테고리),
  favorites_info(관심목록), chatting_room_info(채팅방), chatting_info(채팅내용)
- ※ 원본 명세엔 복붙 오류 있었음(chatting_info에 pw/nick/mail 컬럼 등) — 리빌드에선 정정.

## 7. 리빌드(fairy-next) 반영 현황
| 원본 기획 | 리빌드 반영 |
|----------|------------|
| 편의점 위탁거래 | ✅ store·trade 테이블 + 상태머신(요청→위탁→픽업) |
| 위치기반 편의점 검색 | ✅ 거리순/중간지점(Haversine). 카카오 지도 시각화는 키 받으면 추가 |
| 대/중/소 카테고리 | ✅ 원본 분류 그대로(대11/중34/소161) |
| 실시간 채팅 | ✅ Socket.io |
| 찜 / 마이페이지 / 검색 / 상품CRUD | ✅ |
| 청록 브랜드 + 로고 | ✅ 원본 로고 SVG + teal 테마 |
| **바코드** 발급/소멸 | ❌ 미구현 (위탁 매개를 trade 레코드로 대체) — 추후 추가 가능 |
| **결제 API** | ❌ 미구현 (상태머신만) |
| 자동가입방지(캡차)/일회용·QR 로그인 | ❌ 의도적 제외 (이메일+JWT로 대체) |
| 상점후기/팔로우 | ❌ 자리만 |

> 상세 설계·진행은 `기획_및_DB설계.txt`, `진행상황_이어서할일.txt` 참고.
